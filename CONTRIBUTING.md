# Contributing
Start with docs/roadmap.md and a small reproducible issue. Open an RFC for contract, capability or security changes.
Include requirement IDs, tests, docs and honest status. Run npm test and npm run check.
Do not upload customer records, credentials, private corporate architecture or unreleased vulnerabilities.
AI-assisted contributions are welcome; authors are responsible for correctness, provenance and license compatibility.
Reviewers must not be the same automated principal that authored the change. Maintainers approve changes to grants, release workflows and protected tests.
