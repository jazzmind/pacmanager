# Governance
All software in this repository is Apache-2.0. No paid governance tier is planned.
Repository maintainers own releases and trust policies; community changes use review. Agents are disclosed automation, not maintainers with unlimited authority.
Organizational branding and external claims require approval. Do not claim Plymouth Rock certification, official support or production use without authorization.
Before public operational launch, name at least two maintainers, document succession, configure required reviews and private security reporting. Agent output cannot substitute for those responsibilities.
